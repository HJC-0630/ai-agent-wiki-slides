# Ingest 原始資料來源清單 (5 篇參考文獻)

本 Wiki 共彙整（Ingest）以下 5 份核心技術資料，並經由「先討論架構、後結構化生成」轉化為知識庫條目：

1. **資料一（對應 `01_overview.md`）**：Andrew Ng (2024), *Agentic Design Patterns Part 1: Four Key Design Patterns for AI Agents*（探討 Zero-shot 對話與迭代式工作流的效能差異）。
2. **資料二（對應 `02_planning.md`）**：Shunyu Yao et al. (2023), *ReAct: Synergizing Reasoning and Acting in Language Models*（探討任務拆解、思維鏈與推理行動循環）。
3. **資料三（對應 `03_reflection.md`）**：Noah Shinn et al. (2023), *Reflexion: Language Agents with Verbal Reinforcement Learning*（探討 Actor-Critic 雙角色自我批判與記憶反思機制）。
4. **資料四（對應 `04_patterns_comparison.md`）**：LangGraph 官方技術指南, *Stateful Multi-Actor Applications & Conditional Edges*（探討 DAG 與 StateGraph 的迴圈控制與停止條件設計）。
5. **資料五（對應 `05_case_study.md`）**：自媒體與自動化工作流實作筆記, *Structured JSON Output & Shift-Left Validation for Web Generation*（探討將品質檢查前置於前端 HTML 編譯前的工程最佳實踐）。
