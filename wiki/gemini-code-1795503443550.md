# 01. 什麼是 AI Agent？（與傳統 LLM 的核心差異）

## 1. 核心定義
**AI Agent（人工智慧代理人）** 是指具備環境感知、任務規劃、工具呼叫（Tool Use）以及自我修正能力的自主系統。它不只是被動回答問題的聊天機器人，而是能為了達成特定目標，主動拆解步驟並執行多輪工作流（Agentic Workflow）的智慧系統。

## 2. 傳統 Zero-shot 對話 vs. Agentic 工作流
| 比較維度 | 傳統 Zero-shot 對話 | Agentic 工作流 |
| :--- | :--- | :--- |
| **運作方式** | 單次輸入、單次輸出（一筆畫作畫，不能停頓修改） | 多步驟循環（先列大綱 → 查資料 → 寫草稿 → 檢查修改） |
| **容錯能力** | 中間一旦推理錯誤，後續內容會一路錯到底 | 具備檢查機制（Reflection），能發現錯誤並退回重寫 |
| **知識來源** | 依賴模型訓練時的內部記憶，容易產生幻覺 | 可外部掛載知識庫（如 LLM Wiki）與搜尋工具確保事實正確 |

## 3. 四大經典設計模式（Andrew Ng 架構）
根據吳恩達（Andrew Ng）歸納，Agentic Workflow 最核心的四種設計模式為：
1. **Reflection（反思）**：讓模型審查自己的輸出並改進。
2. **Tool Use（工具使用）**：讓模型呼叫搜尋引擎、程式碼執行器或知識庫。
3. **Planning（規劃）**：讓模型自主決定完成複雜任務的執行步驟。
4. **Multi-agent Collaboration（多代理人協作）**：讓不同角色的 AI 分工合作。
